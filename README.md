Coletânea de geradores de datasets sintéticos desenvolvidos pelo NRA para competições passadas
---

Os scripts e arquivos .blend devem ser ajustados conforme local onde será gerado o dataset (de preferência fora do repositório). Também se faz necessário conferir o número de imagens geradas.

Para todos, é necessário possuir OpenCV e outras dependências instalados diretamente no executável Python utilizado pelo Blender (ou direcionar o uso de Pyenvs).

A saída é um conjunto de imagens + labels anotados automaticamente. Alguns scripts possuem separação val/train.
